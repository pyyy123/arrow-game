# 一箭又一箭 (Arrow Out)

一个使用 Python + Pygame 实现的点击式箭头解谜小游戏。

## 游戏简介

棋盘中分布着上、下、左、右四种方向的箭头。玩家点击箭头时，程序检查该箭头前进方向直到棋盘边界的所有格子：

- 如果路径上**没有其他箭头阻挡**，箭头沿当前方向飞出棋盘并消失；
- 如果路径上**存在其他箭头**，箭头红色闪烁并左右晃动，同时扣除一次失误机会。

每关设有固定的失误次数上限（第 1、2 关为 3 次，第 3 关为 4 次），清空当前关卡全部箭头后进入下一关，失误次数耗尽则本关失败并可重新挑战。
